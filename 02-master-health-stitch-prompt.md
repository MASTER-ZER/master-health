# برومت Google Stitch — Master Health

انسخ النص ده كامل والصقه في Google Stitch:

---

Design a modern, trustworthy medical clinic website called "Master Health" in Arabic (RTL layout). This is a single-doctor clinic website with an appointment booking system.

**Brand identity:**
- Name: Master Health (شعار بسيط بخط واضح، عربي-إنجليزي)
- Tone: calm, professional, clean, trustworthy — this is a healthcare brand, avoid anything flashy or playful
- Primary color: medical blue #2B6CB0
- Secondary/accent color: soft green #38A169 (use sparingly, mainly for confirm/success buttons)
- Background: very light gray-white #F7FAFC
- Text color: dark gray #1A202C (not pure black)
- Error/warning color: soft red #E53E3E
- Font: clean Arabic-friendly typeface (Cairo or Tajawal style), generous line height, large readable body text
- Lots of white space, soft rounded corners (not sharp, not overly playful), minimal visual noise

**Pages to design (RTL, Arabic content):**

1. **Home page**
   - Hero section: doctor's name + specialty + one-line trust statement, prominent "احجز موعدك الآن" button
   - Short "about the doctor" section with a professional photo placeholder
   - Services/specialties list (3-4 cards)
   - Clinic working hours summary
   - Footer with contact info and address

2. **About page (عن العيادة)**
   - Doctor's bio, qualifications, experience (placeholder text)
   - Clinic values/approach (2-3 short points)

3. **Book Appointment page (احجز موعد)**
   - Clean form: patient name, phone number, preferred date, preferred time, optional note
   - Clear submit button using the accent green color
   - Confirmation state design (what the user sees after successful booking)

4. **Contact page (تواصل معنا)**
   - Address, phone numbers, working hours
   - Map placeholder area
   - Simple contact form (optional)

5. **Admin login page (تسجيل دخول)**
   - Minimal, simple email + password form
   - No clinic branding overload — clean utility screen

6. **Admin dashboard (لوحة التحكم)**
   - Table view of bookings: patient name, phone, date, time, status (pending/confirmed/cancelled)
   - Status shown as colored badges (yellow=pending, green=confirmed, red=cancelled)
   - Simple filter/search bar at top
   - Clean, functional, not decorative — this is a working tool for the doctor/staff

**Overall requirements:**
- Fully responsive (mobile-first, since patients will book from phones)
- RTL Arabic layout throughout
- Consistent spacing and button styles across all pages
- Accessibility: high contrast text, large tap targets for buttons
- No stock medical clichés (no generic stethoscope icons everywhere) — keep it modern and minimal
